## Core terminology
Understanding these primary terms will help you set up and navigate PeSofts easily:

- **Assessment/Exam**: A single test instance assigned to test-takers, containing settings, timings, and proctoring policies.
- **Question Bank**: A centralized repository of questions categorized by subject, difficulty, and tags, which can be shared across multiple exams.
- **Proctoring**: Exam monitoring services (automated via AI or conducted live by human proctors) that enforce examination rules.
- **Window Violations**: Event triggers recorded when a candidate switches browser tabs, minimizes the test window, or opens unauthorized software.
- **Browser Lock**: A security setting that prevents students from copying text, right-clicking, or navigating away from the exam page.
