# PeSofts Knowledge & Support Platform

A modern, responsive knowledge base and support community platform built for **PeSofts** (Online Examination, AI Proctoring, and Digital Assessment Software). This platform helps clients, educators, and administrators find documentation, ask questions, and learn best practices.

---

## 🏃 Getting Started

### 1. Install Dependencies
Navigate into the project directory and install the packages:
```bash
cd pesofts-support
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to view the portal.

### 3. Build for Production
```bash
npm run build
npm start
```
